🚀 Étapes pour configurer SMTP
1
Choisissez votre fournisseur email
Utilisez l'adresse email de votre entreprise. Les fournisseurs courants :
📧 Gmail → smtp.gmail.com : 587 📧 Outlook → smtp.office365.com : 587 📧 Brevo → smtp-relay.brevo.com : 587 📧 OVH → ssl0.ovh.net : 587
2
⚠️ Si vous utilisez Gmail — créez un App Password
Gmail bloque votre mot de passe habituel pour les apps tierces. Vous devez créer un mot de passe d'application :
1. Allez sur myaccount.google.com
2. Cliquez sur Sécurité
3. Activez la validation en 2 étapes (obligatoire)
4. Cherchez "Mots de passe des applications"
5. Créez un nouveau mot de passe → choisissez Autre (nom personnalisé) → tapez "GestionCo"
6. Copiez le code de 16 caractères généré → collez-le dans le champ Mot de passe ci-dessous
3
Remplissez les champs ci-dessous
Hôte et Port selon votre fournisseur · Nom d'utilisateur = votre adresse email · Mot de passe = App Password (Gmail) ou mot de passe habituel · Adresse expéditeur = même adresse email
4
Sauvegardez, puis testez
Cliquez sur Sauvegarder, entrez une adresse de test en bas de page, puis cliquez Envoyer un email de test. Si vous recevez l'email, tout est prêt !
💡 Problème fréquent : Si le test échoue avec "Authentication failed", vérifiez que vous utilisez bien l'App Password (16 caractères) et non votre mot de passe Gmail habituel.
